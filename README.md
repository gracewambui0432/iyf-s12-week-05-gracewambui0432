## Project Description

This week, I worked on DOM manipulation and JavaScript events. The main aim was to understand how JavaScript interacts with HTML elements and how to make a webpage respond to user actions.

I practiced selecting elements, changing text and styles, creating new elements, removing elements, and handling different events. I also worked on a to-do list where users can add tasks, mark them as completed, and delete them.

## Features
- Selecting HTML elements using different DOM methods.
- Navigating through parent, child, and sibling elements.
- Changing text and HTML content using JavaScript.
- Updating element attributes and styles.
- Creating, adding, removing, and cloning HTML elements.
- Dynamically adding navigation links.
- Handling mouse and keyboard events.
- Interactive click counter with increase, decrease, and reset buttons.
- Keyboard shortcuts using the event object.
- Event bubbling and event delegation.
- Adding and deleting tasks dynamically.
- Marking tasks as completed.
- Form validation with error messages.

## Lessons Learned

- During this week, I learned how to use JavaScript to interact with HTML elements. I now understand how to select elements using different methods and how to move around the DOM.

- I also learned how to create and remove elements without having to write everything directly in HTML.

- One of the interesting things I learned was event delegation. Instead of adding an event listener to every item, I can add one listener to the parent element and handle events from its children.

- I also practiced form validation, keyboard shortcuts, event bubbling, and responding to mouse clicks.

These exercises helped me understand how interactive websites work.

## Challenges Faced
- Some of the challenges I faced were understanding the different DOM selection methods and knowing when to use each one.

- I also found event bubbling and event delegation a little confusing at first. I solved this by testing different elements and observing what happened when I clicked them.

- Another challenge was form validation, especially displaying error messages and removing them when the user entered correct information.

- Practicing the code and checking the browser console helped me identify and fix mistakes.
